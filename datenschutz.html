2. Allgemeine Hinweise

Der Habit-Tracker ist eine rein clientseitige Web-App. Alle von Ihnen eingegebenen Daten (Gewohnheiten, Häkchen, Einstellungen) werden ausschließlich lokal in Ihrem Browser im LocalStorage gespeichert. Es findet keine Übermittlung Ihrer Daten an einen Server oder an Dritte statt.

3. Datenerfassung auf dieser Anwendung

Diese Anwendung verwendet keine Cookies, keine Analyse-Tools und keine externen Dienste. Es werden keine personenbezogenen Daten erhoben, verarbeitet oder weitergegeben.

4. Lokale Speicherung (LocalStorage)

Ihre Gewohnheiten und Einstellungen werden im LocalStorage Ihres Browsers gespeichert und verbleiben auf Ihrem Endgerät. Sie haben jederzeit die Kontrolle über diese Daten: Über die Funktion „Exportieren“ können Sie eine Sicherung erstellen und über „Importieren“ wiederherstellen. Durch das Löschen der Browserdaten oder der Website-Daten werden die gespeicherten Informationen vollständig entfernt.

5. Ihre Rechte

Da keine personenbezogenen Daten durch den Betreiber verarbeitet werden, bestehen insoweit keine gesonderten Betroffenenrechte. Ihre Daten liegen vollständig in Ihrer eigenen Hand und können jederzeit von Ihnen gelöscht oder exportiert werden.

6. Hosting

Diese statische Anwendung wird ohne serverseitige Verarbeitung ausgeliefert. Beim Aufruf der Website können durch den von Ihnen genutzten Hosting-Anbieter technisch notwendige Zugriffsdaten (z. B. IP-Adresse, Zeitpunkt des Abrufs) verarbeitet werden. Bitte beachten Sie hierzu die Datenschutzhinweise Ihres Hosting- bzw. Bereitstellungsdienstes.
